# React + Vite
This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.
Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## Expanding the ESLint configuration

# Tiffin Service Website

The **Tiffin Service Website** is designed to provide users with an easy and convenient way to browse meal plans and subscribe to daily, weekly, or monthly tiffin services. The website showcases available food menus, pricing, contact details, and allows customers to place orders online. This platform is suitable for local home-cooked meal providers, cafeterias, and tiffin service businesses.

## Features
- Homepage with service introduction and highlights
- Menu section showing daily/weekly meal items
- Subscription plans with pricing
- Customer contact and order form
- Responsive design for mobile and desktop
- Clean and user-friendly layout
